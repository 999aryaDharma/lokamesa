# Global Definition of Done

A sprint is DONE only when all applicable items are true:

- [ ] sprint scope implemented
- [ ] dependencies were already complete
- [ ] unit tests pass
- [ ] integration tests pass
- [ ] required security/safety tests pass
- [ ] golden tests pass where DOCX behavior changes
- [ ] frontend tests/build pass where UI changes
- [ ] no skipped required test
- [ ] no unresolved placeholder markers left for sprint-required behavior
- [ ] acceptance criteria manually checked against sprint spec
- [ ] no unrelated feature scope added
- [ ] docs/ADR updated if architecture changed
- [ ] `git diff` self-reviewed
- [ ] repository verification passes
- [ ] sprint status updated
- [ ] handoff summary written
