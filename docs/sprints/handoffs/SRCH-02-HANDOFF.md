## 1. Executive Summary

`SRCH-02 — Exact Ranked Search` provides real-time lexical search with deterministic ranking and origin-aware snippets over workspace documents. It consumes structured query ASTs generated by `SRCH-01` (`SearchQueryParser`), executes weighted BM25 searches against SQLite FTS5 (`IFtsIndex`), applies strict workspace scoping and document-type filters, and returns ranked snippets with match source labels.

---

## 2. Key Changes & Deliverables

- **`DocumentSearchService`** (`src/DocumentIDE.Core/Search/DocumentSearchService.cs`):
  - Consumes `SearchQuery` AST from `SRCH-01`.
  - Enforces workspace scoping and document filter rules (`type:`, `tag:`, `path:`, `AllowedDocumentIds`).
  - Ranks matches deterministically: Filename exact > Filename partial > Heading > Body > Table > Header/Footer.
  - Generates origin-aware snippets labeled with match sources (`heading`, `body`, `table`, `header`, `footer`).
  - Computes search execution latency (`ExecutionTimeMs`).
- **Domain Models & Options** (`src/DocumentIDE.Core/Search/DocumentSearchService.cs`):
  - `DocumentSearchOptions`, `DocumentSearchResult`, `DocumentSearchResponse`.
- **Unit & Integration Test Suites**:
  - `tests/DocumentIDE.Core.Tests/Search/DocumentSearchServiceTests.cs` (Unit tests for filtering, empty queries, invalidation)
  - `tests/DocumentIDE.IntegrationTests/Search/ExactSearchTests.cs` (Integration tests for exact filename outranking body, table/header source labels, workspace scope enforcement)
