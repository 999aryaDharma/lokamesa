# 00 — Brand Brief

**Status:** Draft v0.1
**Owner:** project owner
**Terakhir diperbarui:** 2026-10-18

## 1. Satu kalimat

**Lokamesa adalah meja kerja lokal untuk dokumen serius dan pikiran yang belum jadi.**

## 2. Masalah yang diselesaikan

Pengetahuan kerja orang terpecah menjadi dua dunia yang tidak pernah bertemu:

- **Dokumen serius** hidup di Word, folder jaringan, dan repo Git. Alatnya kuat, tetapi kaku, tersebar, dan tidak punya tempat untuk ide setengah matang.
- **Pikiran lepas** hidup di aplikasi catatan yang menyenangkan, tetapi tidak bisa dipercaya untuk dokumen yang harus dikirim ke klien, di-review, atau di-version.

Akibatnya orang memakai 4–6 aplikasi, menyalin-tempel, dan kehilangan konteks: *"di mana catatan rapat yang jadi dasar proposal ini?"*

Aplikasi cloud menyelesaikan sebagian masalah itu dengan menukar kepemilikan: file berada di server orang lain, dalam format yang tidak bisa dibuka tanpa aplikasi tersebut.

## 3. Positioning statement

> Untuk **profesional yang bekerja dengan dokumen dan ide sekaligus** — konsultan, penulis teknis, peneliti, dan tim kecil — yang **lelah berpindah antara aplikasi catatan dan alat dokumen**, Lokamesa adalah **ruang kerja lokal berbasis canvas** yang **menyatukan dokumen serius dan pikiran lepas di satu tempat**, berbeda dari aplikasi cloud karena **semua isi tetap berupa file di mesinmu, dalam format terbuka**.

## 4. Janji merek

Tiga janji yang harus selalu benar, di setiap layar dan setiap materi:

1. **Milikmu.** File tetap di disk-mu. Formatnya terbuka. Kalau Lokamesa hilang, isinya tetap terbuka.
2. **Terlihat semua.** Canvas membuat hubungan antar dokumen, ide, dan referensi terlihat sekaligus, bukan tersembunyi di pohon folder.
3. **Serius, tapi tidak kaku.** Alat dokumen tetap sungguhan (Word, DOCX, Git, pencarian), sementara ruang berpikir tetap bebas.

## 5. Audiens

### Primer

| Segmen | Kenapa cocok |
|---|---|
| **Konsultan & penulis proposal** | Menghasilkan DOCX berulang, butuh riwayat versi, template, dan bukti perubahan |
| **Penulis teknis / engineer-writer** | Menulis Markdown, memakai Git setiap hari, menolak lock-in |
| **Peneliti & analis** | Mengumpulkan sumber, PDF, catatan, dan referensi visual dalam satu proyek |

### Sekunder

| Segmen | Kenapa cocok |
|---|---|
| **Tim kecil (2–10 orang)** | Butuh berbagi terkontrol tanpa memindahkan seluruh arsip ke cloud |
| **Operator/admin dokumen** | Pekerjaan batch berulang (rename, ganti teks, ekspor PDF) dengan pratinjau aman |

### Bukan audiens (untuk sekarang)

- tim enterprise yang membutuhkan kolaborasi real-time dan SSO,
- pengguna yang hanya butuh catatan pribadi sederhana,
- pengguna yang menginginkan semua data di cloud dan diakses dari banyak perangkat tanpa file lokal.

## 6. Diferensiasi

| Pilar | Bukti yang harus terlihat |
|---|---|
| **Local-first, bukan cloud-first** | File di disk; tanpa server sebagai sumber kebenaran; aplikasi tetap berguna offline |
| **Canvas sebagai rumah, bukan gimmick** | Dokumen, ide, referensi, dan grup berada di satu bidang yang bisa diatur |
| **Dokumen serius tetap serius** | DOCX dibuka di Microsoft Word; Git nyata; pencarian terstruktur; batch dengan pratinjau |
| **Format terbuka** | `.md`, `.docx`, file media biasa — bukan format proprietary |

## 7. Anti-positioning

Lokamesa **bukan**:

- "Notion/Obsidian killer" — bukan perlombaan fitur catatan,
- aplikasi AI yang mengambil keputusan untukmu,
- pengganti Microsoft Word untuk editing DOCX mendalam,
- layanan cloud dengan akun wajib,
- aplikasi kolaborasi real-time,
- tempat menyimpan rahasia tanpa backup (lihat §8).

## 8. Kejujuran yang harus dijaga

Merek yang tenang tidak boleh berbohong. Materi pemasaran **wajib** menyebut:

- sinkronisasi cloud belum ada; backup adalah tanggung jawab pengguna (kami menyediakan ekspor dan folder vault),
- wildboard adalah ruang kerja, bukan jaminan arsip jangka panjang,
- DOCX editing mendalam tetap di Word,
- berbagi bersifat eksplisit dan tidak otomatis.

## 9. Arsitektur nama

| Nama | Baca | Peran | Aturan tulis |
|---|---|---|---|
| **Lokamesa** | lo-ka-ME-sa | nama produk | satu kata, kapital hanya `L`; lowercase `lokamesa` hanya untuk wordmark digital |
| **Mesa** | MEH-sa | mode dokumen | kapital `M` |
| **Loka** | LOH-ka | mode wildboard | kapital `L` |

Alasan nama: **loka** (tempat, akar *lokasi*) + **mesa** (meja). Menggabungkan local-first dan permukaan kerja visual. Bunyi "loka" juga memicu asosiasi *local* tanpa ambiguitas ejaan.

Aturan:

- Jangan menulis "Loka Mesa" atau "LokaMesa".
- Jangan menerjemahkan nama mode ke bahasa lain.
- Jangan memakai "Loka" sebagai nama produk — itu nama mode.
- Deskriptor produk: **"Lokamesa — local-first document canvas"**.

## 10. Kepribadian merek

| Kami adalah | Kami bukan |
|---|---|
| Tenang dan percaya diri | Ramai dan persuasif |
| Konkret dan spesifik | Penuh superlatif |
| Hangat dan manusiawi | Korporat dan dingin |
| Lokal dan bisa dipegang | Abstrak dan "di awan" |
| Jujur soal batasan | Menjanjikan segalanya |

## 11. Kriteria keberhasilan merek

- Orang bisa mengeja **Lokamesa** setelah mendengarnya sekali.
- Orang menjelaskan produknya dengan kalimat "tempat kerja lokal untuk dokumen dan ide", bukan "aplikasi catatan".
- Materi tidak pernah menyembunyikan bahwa sync belum ada.
- Nama **Mesa** dan **Loka** dipakai konsisten di produk, dokumen, dan pemasaran.
