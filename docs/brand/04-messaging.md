# 04 — Messaging

**Status:** Draft v0.1
**Tujuan:** satu bahasa untuk situs, deck, README, dan percakapan penjualan.

## 1. Positioning (ringkas)

Lokamesa adalah ruang kerja lokal untuk dokumen serius dan pikiran yang belum jadi.

## 2. Satu kalimat

| Konteks | Kalimat |
|---|---|
| Sangat pendek | **Meja kerja lokal untuk dokumen dan ide.** |
| Pendek | **Dokumen serius dan pikiran lepas, di satu meja yang milikmu.** |
| Menengah | **Lokamesa menyatukan DOCX, Markdown, Git, dan catatan liar di satu canvas lokal — file tetap di mesinmu, dalam format terbuka.** |

## 3. Boilerplate

### 25 kata

> Lokamesa adalah ruang kerja lokal untuk dokumen dan ide. Kelola DOCX, Markdown, dan Git di **Mesa**, tuangkan pikiran dan referensi di **Loka**. Semua file tetap di mesinmu.

### 50 kata

> Lokamesa adalah ruang kerja lokal untuk dokumen serius dan pikiran yang belum jadi. Di **Mesa** kamu mengelola DOCX, Markdown, Git, dan pencarian seperti di IDE. Di **Loka** kamu menuangkan ide, sticky note, dan referensi visual tanpa struktur. Semua tersimpan sebagai file terbuka di mesinmu — bukan di cloud.

### 100 kata

> Lokamesa adalah ruang kerja lokal untuk orang yang bekerja dengan dokumen dan ide sekaligus. Ia menggabungkan dua hal yang biasanya terpisah: alat dokumen yang serius dan ruang berpikir yang bebas.
>
> Di **Mesa**, dokumen DOCX dibuka di Microsoft Word, Markdown tetap `.md`, Git tetap Git, dan pencarian bekerja lintas format. Di **Loka**, kamu meletakkan sticky note, sheet, gambar, dan referensi di canvas tanpa harus memilih folder lebih dulu.
>
> Tidak ada akun wajib dan tidak ada server sebagai sumber kebenaran. File tetap di disk-mu, dalam format yang bisa kamu buka tanpa Lokamesa.

## 4. Pilar nilai

| Pilar | Janji | Bukti yang harus disebut |
|---|---|---|
| **Milikmu** | File tetap di mesinmu, format terbuka | `.md` dan `.docx` biasa; tidak ada database proprietary |
| **Terlihat semua** | Canvas memperlihatkan hubungan, bukan menyembunyikannya | Canvas, graph, backlink |
| **Serius** | Alat dokumen tetap sungguhan | Word untuk DOCX, Git nyata, batch dengan pratinjau |
| **Bebas** | Ada tempat untuk ide yang belum jadi | Loka: sticky, sheet, stack, capture |

## 6. Objection handling

| Keberatan | Jawaban |
|---|---|
| "Ini cloud, kan?" | Tidak. File ada di disk-mu. Tidak ada server sebagai sumber kebenaran dan tidak ada akun wajib. |
| "Apakah menggantikan Word?" | Tidak. DOCX dibuka dan diedit di Microsoft Word. Lokamesa mengelola, mencari, dan membandingkan. |
| "Kalau laptop hilang?" | Backup adalah tanggung jawabmu; kami menyediakan ekspor dan vault folder yang bisa disalin. Sinkronisasi cloud belum ada — dan kami mengatakannya. |
| "Bedanya dengan Notion/Obsidian?" | Fokusnya dokumen kerja nyata (DOCX, Git, batch) plus canvas untuk ide. Bukan perlombaan fitur catatan. |
| "Apakah ada AI?" | Ada pencarian semantik lokal (opsional). Kami tidak menjanjikan AI yang mengambil keputusan untukmu. |
| "Apakah file saya terkunci?" | Tidak. Markdown tetap `.md`, DOCX tetap `.docx`, gambar tetap file biasa. |
| "Bisa kolaborasi real-time?" | Belum. Berbagi bersifat eksplisit lewat tautan, bukan pengeditan bersamaan. |

## 7. Kebijakan klaim

**Boleh diklaim** (dengan bukti):

- local-first, file di disk, format terbuka,
- canvas, graph, backlink,
- DOCX dibuka di Word,
- Git source control,
- pencarian lintas format,
- batch dengan pratinjau dan undo.

**Tidak boleh diklaim** sampai benar-benar ada:

- "sinkronisasi otomatis antar perangkat",
- "kolaborasi real-time",
- "pengganti Word",
- "AI yang menulis untukmu",
- "enterprise-grade security" tanpa audit.
