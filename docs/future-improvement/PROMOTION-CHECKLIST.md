# Future Improvement Promotion Checklist

Use this checklist before moving a roadmap version into the active implementation board.

- [ ] Owner confirms the product scope.
- [ ] Feature spec is still compatible with the current master spec.
- [ ] All referenced V1 dependencies are still valid.
- [ ] No product-level branch-management behavior has been added.
- [ ] Planned files are reconciled with the actual repository structure.
- [ ] Database migrations, if any, are identified.
- [ ] Security/file-safety implications are reviewed.
- [ ] UX/accessibility expectations are testable.
- [ ] Performance budget is explicit.
- [ ] Sprint IDs are added to the active manifest.
- [ ] Active status board is updated.
- [ ] Execution waves are recomputed.
- [ ] Release notes/changelog scope is identified.
