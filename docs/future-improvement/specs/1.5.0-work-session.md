# 1.5.0 — Work Session

**Label:** `future-improvement`
**Status:** Specified
**Primary outcome:** durable “what I am working on” context across interruptions and restarts

## 1. Purpose

Create a first-class, resumable unit of human work that groups workspace activity without pretending to be a Git commit.

## 2. Domain model

```text
WorkSession
- id
- workspace_id
- name
- status
- started_at
- last_active_at
- ended_at
- selected_document_ids
- saved_view_id
- review_session_id
- git_context_json
- activity_summary_json
```

Status:

```text
active
paused
completed
archived
```

## 3. Activity model

A session may reference:

- documents opened,
- Document IDE operations,
- batch operations,
- review activity,
- source-control changes/commits,
- context-pack creation,
- saved view changes.

The session references existing history/events rather than duplicating document contents.

## 4. External activity

Changes detected from Word, Explorer, VS Code, or another application may appear as `external activity` when the source is known to be outside Document IDE. The UI must not claim stronger attribution than the watcher evidence supports.

## 5. Resume

On reopen the application may offer:

```text
Resume Work Session
Production v1 documents

17 documents
8 Git changes
2 pending review items
```

Resuming restores application context such as active workspace, view, selected documents, review position, and canvas viewport where safely available.

It does not restore arbitrary file contents.

## 6. Git relationship

A session may link to one or more Git commits. It must not create a proprietary commit or imply that one session equals one commit.

## 7. Expiration

Work sessions are user history, not recovery snapshots. Cleanup policy must be separate from the 30-day recovery snapshot policy. Default retention should be configurable in a later patch release; V1.5.0 only needs explicit archive/delete.

## 8. Non-goals

- time tracking/payroll,
- automatic billing,
- task management suite,
- autonomous session naming from external cloud AI.
