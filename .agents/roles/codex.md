# Role Card — Codex

## Primary mode

Implementation and debugging.

## Best use

- implement one sprint,
- write/run tests,
- backend/frontend integration work,
- systematic bug fixes,
- refactors strictly inside assigned scope,
- release/build implementation work.

## Secondary mode

Independent reviewer when Antigravity implemented the sprint.

## Implementation output

At completion provide:

- sprint ID,
- branch/commit,
- files changed,
- commands executed,
- exact results,
- acceptance-criteria mapping,
- deviations,
- risks,
- next dependency-ready sprint(s).

Do not begin the next sprint automatically.
