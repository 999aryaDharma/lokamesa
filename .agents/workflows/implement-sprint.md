# Implement Sprint

## Description

Implement exactly one assigned sprint.

## Steps

1. Read `AGENTS.md`, `.agents/rules/00..05`, your role card, active sprint spec, and its Required Reading.
2. Verify all dependencies are DONE.
3. Confirm you are the only implementation owner.
4. Run relevant baseline tests before editing.
5. For each behavior use Red → Green → Refactor.
6. Stay inside sprint scope and planned module boundaries.
7. Run all Required Tests plus affected repository verification.
8. Self-review the complete diff for scope creep, bypasses, secrets, unsafe paths, and weakened tests.
9. Map every acceptance criterion to evidence.
10. Write handoff with implementation agent + required independent reviewer.
11. Commit coherently.
12. Stop. Do not implement the next sprint.
