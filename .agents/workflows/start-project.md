# Start Project

## Description

One-time repository onboarding and first implementation sprint.

## Steps

1. Read `AGENTS.md`, `.agents/README.md`, core rules, master spec, architecture spec, implementation plan, sprint index, and sprint status.
2. Confirm repository baseline and required development tools.
3. Confirm only `FND-01` is initially READY unless status shows otherwise.
4. Assign implementation owner. Default: Codex.
5. Implement only `FND-01` using its embedded sprint protocol.
6. Run sprint tests and repository verification.
7. Create handoff.
8. Send implementation to the other agent for independent review.
9. Do not start another sprint until review is approved and status is DONE.
